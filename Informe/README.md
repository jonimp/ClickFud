# M&A Financial Due Diligence Report

A practical diligence starter for scope, financial normalization, working
capital, quality-of-earnings findings, requests, and transaction decisions.

The research candidate is the selected `financial-due-diligence-report`
directory in [Shahriar Labs' LaTeX Templates](https://github.com/shihabshahrier/Latex_Templates/tree/main/finance/financial-due-diligence-report),
licensed MIT. This catalogue starter is original content and does not bundle
upstream files, logos, or transaction data.

Compile `main.tex` with PDFLaTeX.
